  - TODAY 時：右箭頭改為列表 icon → 進入 1210
  - 單點日期文字 → query 該日資料，檢索失敗彈窗「此筆資料不存在」
- TODO 項目列表
  - 圓圈 checkbox + 名稱 + 🥕數
  - 可拖曳排序
  - 長按 → 編輯（名稱、積分、循環次數、循環週期）
  - 左滑 → 彈出垃圾桶選項可刪除
  - 打勾 → 灰調 + 刪除線 + 自動沉到列表最底 + 鼓勵語 toast
- 底部 +新增 按鈕

### TODO 建立邏輯
1. 進入當日畫面時，檢查前一日是否有未完事項
2. 如有 → 自動複製到今日，每拖欠一天在名稱前加一個 `!`
3. 如完全無未完事項 → 自動建立一筆 TODO_Temp 供編輯
4. TODO_Temp 每天最多一筆，日結自動消失（不會被複製到隔天）

### TODO 屬性
| 欄位 | 預設 | 說明 |
|------|------|------|
| 名稱 | 空 / TODO_Temp | 必填 |
| 🥕 積分 | 1 | 編輯時可改 |
| 循環次數 | 1（單次） | 可設定重複次數 |
| 循環週期 | 不開放 | 單次時不開放；循環次數 > 1 時可設週期 |

## 1300 Routine 主頁

### 元件
- 上方：日期 BAR（同 1200 TODO 邏輯，可切日期，TODAY 右箭頭→1320）
- 中間：圓圈
  - 有對應 routine → 顯示被選取 Block 第一個 Step 的 分:秒 + Play 按鈕
  - 無對應 routine → 圓圈反灰，Play 不可按
  - 預設選取 = block-rise 匹配的 Block
  - 手動選取 = 從 1310 選的 Block
- 下方：回顧按鈕→1320 ｜ routine 選擇→1310
- Play → 進入 1301 計時進行

### Block-rise vs 計時起算
- **block-rise** = 畫面偵測用。時間一過，打開 1300 頁面自動顯示對應 Block
- **計時起算** = Routine 步驟的時間規劃基準。可與 block-rise 不同
- **block-set** = Routine 結束時間
- 有填 rise/set = 每日循環自動出現；不填 = 一次性 Block

### Data Schema

```abap
* Block
begin of t_block,
  b_index type i,          "索引碼(PK)
  b_name  type string,     "block名稱(必填)
  b_rise  type char4,      "偵測ON時間(空=一次性)
  b_start type char4,      "計時起算時間(步驟規劃基準，可與rise不同)
  b_set   type char4,      "偵測OFF時間(空=一次性)
end of t_block.

* Step
begin of t_step,
  b_index type i,          "block索引碼(PK+FK)
  s_index type i,          "索引碼(PK)
  s_name  type string,     "step名稱(必填)
  s_time  type i,          "本step花費秒數
  s_prebuffer type i,      "本step開始前緩衝秒數(預設+最低10秒)
end of t_step.
```

### Block 規格
- 可自訂名稱、步驟、時間
- 可設 block-rise / block-set（也可不設，臨時用途如一桌大餐的多菜時間差控制）
- Step 可自訂名稱 + 秒數 + pre-buffer（本 Step 開始前緩衝秒數，預設+最低 10 秒）

### 積分（寫死）
| Block 完成度 | 🥕 |
|------------|-----|
| 0% | 0 |
| 1-20% | 1 |
| 21-40% | 2 |
| 41-60% | 3 |
| 61-80% | 4 |
| 81-100% | 5 |

## 1400 學習主頁

### 元件
- 上方：日期 BAR（同 TODO/Routine 邏輯）
- 中間：今日認領的 Quest（無上限，推薦 2 個）
  - 每個顯示：Skill 名 + Quest 名 + 目標量 + 實際量 + %
  - 點擊可直接填寫實際進度（隨時可填）
- 認領按鈕 → 1401 認領列表
- 下方：技能列表→1410 ｜ 回顧→1420

### 積分（寫死）
| 當日 Quest 完成度 | 🥕 |
|-----------------|-----|
| 0-50% | 0 |
| 50.01-100% | 1 |
| 超過 100% | 2 |

### Data Schema

```abap
* Skill（技能）
begin of t_skill,
  sk_index type i,         "索引碼(PK)
  sk_name  type string,    "技能名稱(必填)
  sk_category type string, "分類(工作/語言/閱讀/其他)
end of t_skill.

* Quest（子任務）
begin of t_quest,
  sk_index type i,         "技能索引碼(PK+FK)
  q_index  type i,         "索引碼(PK)
  q_name   type string,    "子任務名稱(必填)
  q_unit   type string,    "單位(頁/題/章/篇)
  q_total  type i,         "總量(無序任務填0)
  q_done   type i,         "已完成量
  q_seq    type i,         "排序(>0=有序, 0=無序/重複型)
  q_freq   type string,    "頻率(每日/每週/每月/不限)
end of t_quest.

* Daily Claim（每日認領）
begin of t_claim,
  c_index  type i,         "索引碼(PK, auto-increment)
  c_date   type char8,     "日期
  sk_index type i,         "技能索引碼(FK)
  q_index  type i,         "Quest索引碼(FK)
  c_target type i,         "今日目標量
  c_actual type i,         "今日實際量(隨時可填)
end of t_claim.
```

### 自動推薦邏輯
- 有序 Quest（q_seq > 0）：找該 Skill 最後完成的 Quest，推薦 q_seq + 1
- 無序 Quest（q_seq = 0）：直接再推薦同一筆（每天讀一篇文章）

## 1500 設定

### 進入方式
- 從 1100 儀表板右上角 ⚙️ 齒輪按鈕

### 元件
- 🔔 通知/提醒開關
- 🔊 提示音設定
  - 總開關
  - 音量調節
  - 各場景個別開關（Routine 提示 / TODO 完成 / 商店）
- 💾 資料備份/匯出（IndexedDB → JSON 匯出）
- 🐰 小蘿自訂（未來擴充用，暫時空）
- ℹ️ 關於（版本號、致謝）

### 音效設計原則（ASD 友善）
- 不用急促、尖銳、高頻的提示音
- 用節奏重但柔和的輕快音效（木琴、低音鼓點）
- Routine 5 秒倒數高亮不用蜂鳴，改用節奏漸強的鼓點
- 未來可替換為自訂音源（懷安的聲音）

## 1600 商店

### 進入方式
- 從 1100 儀表板右上角 🏪 商店按鈕

### 元件
- 🥕 目前積分顯示
- 🎰 抽獎區：選等級 → 付固定🥕 → 隨機抽一個微冒險
- 🛒 貨架區：瀏覽完整微冒險清單 → 選中付隨機🥕兌換
- 📋 已兌換清單：進行中/已完成的微冒險

### 定價規則

**抽獎（固定價格）= min + 2^lv**
| 等級 | 價格 |
|------|------|
| Lv1 散步 | 5+2=7🥕 |
| Lv2 探索 | 15+4=19🥕 |
| Lv3 遠征 | 50+8=58🥕 |
| Lv4 史詩 | 100+16=116🥕 |

**貨架（隨機價格）= min + dice(max-min)**
| 等級 | 價格範圍 |
|------|---------|
| Lv1 散步 | 5~10🥕 |
| Lv2 探索 | 15~30🥕 |
| Lv3 遠征 | 50~80🥕 |
| Lv4 史詩 | 100~200🥕 |

### 重抽
- 抽到不可抗力做不了的 → 重抽費用 +1🥕（固定，不累加）
- 免費重抽 1 次

### 完成返還
- 完成微冒險後返還購買價格的 50%（四捨五入）

### 微冒險池
- Lv1 散步級 24 個
- Lv2 探索級 24 個
- Lv3 遠征級 12 個
- Lv4 史詩級 12 個
- 完整清單見 `adventures.json`
