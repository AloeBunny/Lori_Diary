## Claude Design 提示詞

請為「小蘿日誌」設計 Mobile PWA 的 UI 介面。以下是完整規格：

### 產品概述
小蘿日誌是一款個人養成 PWA App，結合 TODO 待辦、Routine 計時器（仿 HIIT）、學習進度追蹤、積分商店四大模組。吉祥物是一隻叫「小蘿」的 ASCII 兔子。目標裝置是 iPhone 14 Plus（Safari 加到主畫面）。

### 設計風格
- **品牌語言**：COS × Aesop × Kinfolk × Diptyque 交集——極簡、有溫度、不張揚
- **視覺調性**：節制的暖色系，大面積中性色，彩色只在互動元素出現
- **排版**：留白充裕、呼吸感、大觸控區域（手指友善）
- **字體**：系統字體 -apple-system, BlinkMacSystemFont
- **圖標**：線條式，不用填充式
- **圓角**：12px 統一
- **ASD 友善設計**：不用急促動畫、不用閃爍效果（除 Routine 倒數最後 5 秒用溫和的節奏漸強）、視覺層次清晰、資訊密度適中

### 通用元件

**底部 Tab Bar（4 tab）**
📊 儀表板 | ✅ 一般 | ⏱ Routine | 📖 學習

**日期 BAR（1200/1300/1400 共用）**
- 綠色底色塊，色塊寬度 = 進度%
- 左右箭頭切日期
- TODAY 時右箭頭改為列表 icon
- 點日期文字可 query 單日

**列表項目**
- 白色卡片、12px 圓角、1px 邊框 `#E8E4DE`
- 左滑顯示刪除按鈕（紅色）
- 點擊進入編輯
- 底部固定 +新增按鈕（列表可滾動，按鈕固定在 tab 上方）

**編輯頁面**
- 左上退出按鈕 / 右上存檔按鈕
- 表單欄位垂直排列

**Toast 通知（鼓勵語）**
- 畫面中央彈出，海軍藍底白字，16px，3 秒消失
- 進入動畫：scale 0.8→1 + fade in

### 畫面清單（共 21 個）

請依照以下畫面逐一設計 mockup：

**1000 封面**：深色底（`#3A3F47`）居中 ASCII 小蘿兔子（隨機表情，如 `(\(\ / ( -ω-) ♡ / o_(")(")` 或 `(\(\ / ( >ω<) ✧ / o_(")(")` 等），下方「🥕小蘿日誌🥕」標題，底部 START 按鈕（薄荷鼠尾草色圓角按鈕）

**1100 儀表板**：右上角 ⚙️+🏪 兩個 icon 按鈕。上方 🥕 積分大數字（紅蘿蔔色），圓環進度圈（薄荷色弧線+中央%），中間熱力圖（7列×N行方塊，每格隨機色濃淡），下方月曆

**1110 進度條明細**：頂部日期+整體%（綠色膠囊條），下方三條分類膠囊進度條：待辦（藍）、日常循環（灰）、學習（黃）

**1200 TODO 當日**：日期BAR + TODO 列表（圓圈checkbox + 名稱 + 🥕數）。完成項灰調+刪除線+沉底。底部 +新增

**1210 TODO 列表**：日期色塊按鈕堆疊，首筆為今日（最深色），越舊越淺，每塊含進度條

**1300 Routine 主頁**：日期BAR，中央大圓圈顯示 mm:ss + Play 三角按鈕（霧紫色），下方兩個按鈕「回顧」「Routine 選擇」

**1301 計時進行**：全畫面倒數，大字 mm:ss（海軍藍），上方當前 Step 名稱，下方兩個圓角按鈕「完成 ✓」（薄荷色）「跳過 →」（灰色）。最後 5 秒背景用節奏漸強的溫和色彩變化（不要急促閃爍）

**1302 完成摘要**：頂部大字完成%，🥕 獲得數，下方列出被跳過的 Step 每個旁邊有 ▶ 補做按鈕（霧紫），底部確認按鈕

**1310 Block 列表**：卡片式列表，每張卡片左側色條顯示完成%，名稱+時間資訊。底部 +新增Block

**131A Block 編輯**：表單——名稱輸入框、block-rise 時間選擇器、block-set 時間選擇器、Play 按鈕（霧紫圓角）、底部 STEP_BAR 大按鈕

**1311 Step 列表**：條狀列表，每條顯示 Step 名稱 + 時間 + pre-buffer。底部 +新增Step

**131B Step 編輯**：表單——名稱、花費秒數（數字輸入）、pre-buffer 秒數（數字輸入，預設10）

**1320 Routine 日期列表**：日期列表+百分比進度條（同 1210 結構）

**1400 學習主頁**：日期BAR，中間今日認領 Quest 卡片（Skill 名+Quest 名+目標/實際+%進度條），認領按鈕，下方「技能列表」「回顧」

**1401 認領列表**：上方推薦區（2 個 Quest 卡片帶 checkbox），分隔線，下方完整列表（checkbox 勾選），底部確認按鈕

**1410 技能列表**：卡片式，每個 Skill 顯示名稱+分類標籤+整體進度%。底部 +新增Skill

**141A Skill 明細**：Skill 屬性表單 + Quest 列表（帶 checkbox 可認領）+ 底部 +新增Quest

**141B Quest 編輯**：表單——名稱、單位、總量、排序（有序/無序切換）

**1420 學習日期列表**：同 1210/1320 結構

**1500 設定**：選單式列表——通知開關、提示音設定（總開關+音量+場景個別）、資料備份、小蘿自訂、關於

**1600 商店**：頂部 🥕 積分餘額。分兩個 tab 或區塊：抽獎（四個等級按鈕，付🥕抽）+ 貨架（微冒險卡片瀑布流，每張顯示名稱+等級+隨機價格+兌換按鈕）。底部已兌換清單入口
